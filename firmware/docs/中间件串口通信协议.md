# 单片机与中间件之间的串口通信协议

> 适用模块：`motor_task`（`App/motor_task.c` / `App/inc/motor_task.h`）
> 物理层：USART1，波特率 921600，DMA 空闲中断接收

---

## 1. 帧格式

### 1.1 通用帧结构

| 字段       | 长度 (字节) | 值 / 说明                           |
| ---------- | ----------- | ------------------------------------ |
| HEADER_0   | 1           | `0x5A`                               |
| HEADER_1   | 1           | `0xA5`                               |
| CMD        | 1           | 命令码（见 §2 / §3）                |
| LEN        | 1           | DATA 字段的字节长度                  |
| DATA       | LEN         | 有效载荷（可为空）                   |
| CHK        | 1           | 校验和（见 §1.2）                    |
| TAIL_0     | 1           | `0x0D` (`\r`)                        |
| TAIL_1     | 1           | `0x0A` (`\n`)                        |

- **最短帧长度**：7 字节（HEADER×2 + CMD + LEN + CHK + TAIL×2，此时 LEN = 0）。
- **多字节字段（float）** 采用小端序（Little-Endian），直接 `memcpy` 自/到 `float`，IEEE 754 单精度。

### 1.2 校验和算法

```
CHK = CMD XOR LEN XOR DATA[0] XOR DATA[1] XOR ... XOR DATA[LEN-1]
```

逐字节异或，不包含帧头、帧尾本身。

---

## 2. 命令码（中间件 → 单片机）

### 2.1 使能 / 失能

| CMD   | 名称         | DATA 长度 | DATA 格式                        | 说明                          |
| ----- | ------------ | --------- | -------------------------------- | ----------------------------- |
| `0x01` | CMD_ENABLE   | 1         | `[motor_id]`                     | `motor_id = 0` 表示全部电机   |
| `0x02` | CMD_DISABLE  | 1         | `[motor_id]`                     | `motor_id = 0` 表示全部电机   |

- `motor_id` 有效范围：`1 ~ 6`（共 6 个电机），`0` = 广播全部。

### 2.2 单电机控制命令

| CMD   | 名称         | DATA 长度 | DATA 格式                                                                                   |
| ----- | ------------- | --------- | ------------------------------------------------------------------------------------------- |
| `0x03` | CMD_MIT_CTRL  | 21        | `[id, pos(F), vel(F), kp(F), kd(F), tor(F)]`                                                |
| `0x04` | CMD_POS_CTRL  | 9         | `[id, pos(F), vel(F)]`                                                                       |
| `0x05` | CMD_SPD_CTRL  | 5         | `[id, vel(F)]`                                                                               |
| `0x06` | CMD_PSI_CTRL  | 13        | `[id, pos(F), vel(F), cur(F)]`                                                               |

- `id`：1 字节，电机编号 `1 ~ 6`。
- `(F)` = 4 字节 IEEE 754 float，小端序。

**MIT 模式详解（CMD = `0x03`）：**

| 偏移 | 长度 | 类型  | 说明       |
| ---- | ---- | ----- | ---------- |
| 0    | 1    | uint8 | 电机 ID    |
| 1    | 4    | float | 目标位置   |
| 5    | 4    | float | 目标速度   |
| 9    | 4    | float | 位置增益 Kp |
| 13   | 4    | float | 速度增益 Kd |
| 17   | 4    | float | 前馈力矩   |

### 2.3 状态查询

| CMD   | 名称           | DATA 长度 | DATA 格式        |
| ----- | -------------- | --------- | ---------------- |
| `0x07` | CMD_READ_STATUS | 1         | `[motor_id]`    |

- 单片机收到后返回一条 `RSP_STATUS`（见 §3.1）。

### 2.4 维护命令

| CMD   | 名称           | DATA 长度 | DATA 格式        | 说明                          |
| ----- | -------------- | --------- | ---------------- | ----------------------------- |
| `0x08` | CMD_SAVE_ZERO  | 1         | `[motor_id]`     | 保存当前为零点；`0` = 全部    |
| `0x09` | CMD_CLEAR_ERR  | 1         | `[motor_id]`     | 清除电机错误；`0` = 全部      |
| `0x0A` | CMD_LOCK_MOTOR | 1         | `[motor_id]`     | 锁定电机（高 Kp MIT 保持）；`0` = 全部 |

### 2.5 批量控制命令（6 电机同时控制）

| CMD   | 名称           | DATA 长度 | DATA 格式                                                                        |
| ----- | -------------- | --------- | -------------------------------------------------------------------------------- |
| `0x10` | CMD_ALL_POS    | 24        | `[pos1(F), pos2(F), pos3(F), pos4(F), pos5(F), pos6(F)]`                         |
| `0x11` | CMD_ALL_TORQUE | 24        | `[tor1(F), tor2(F), tor3(F), tor4(F), tor5(F), tor6(F)]`                         |
| `0x12` | CMD_ALL_MIT    | 120       | `[motor1(pos,vel,kp,kd,tor), motor2(...), ..., motor6(...)]`                     |

> `(F)` = 4 字节 float。电机按顺序排列，电机 1 在前，电机 6 在后。

**CMD_ALL_MIT 详细布局（每个电机 20 字节）：**

| 偏移        | 长度 | 类型  | 说明       |
| ----------- | ---- | ----- | ---------- |
| i×20 + 0    | 4    | float | 目标位置   |
| i×20 + 4    | 4    | float | 目标速度   |
| i×20 + 8    | 4    | float | 位置增益 Kp |
| i×20 + 12   | 4    | float | 速度增益 Kd |
| i×20 + 16   | 4    | float | 前馈力矩   |

> `i` = 0 ~ 5，对应电机 1 ~ 6。

## 3. 应答码（单片机 → 中间件）

### 3.1 状态应答 RSP_STATUS（CMD = `0x80`）

| 偏移 | 长度 | 类型    | 说明                |
| ---- | ---- | ------- | ------------------- |
| 0    | 1    | uint8   | 电机 ID             |
| 1    | 1    | uint8   | 电机状态 (state)    |
| 2    | 4    | float   | 当前位置 (pos)      |
| 6    | 4    | float   | 当前速度 (vel)      |
| 10   | 4    | float   | 当前力矩 (tor)      |
| 14   | 1    | uint8   | MOSFET 温度 (Tmos)  |
| 15   | 1    | uint8   | 线圈温度 (Tcoil)    |

- DATA 总长：**16 字节**。

### 3.2 成功应答 RSP_ACK（CMD = `0xFE`）

| 偏移 | 长度 | 类型  | 说明                  |
| ---- | ---- | ----- | --------------------- |
| 0    | 1    | uint8 | 被确认的原始命令码 CMD |

- DATA 总长：**1 字节**。

### 3.3 错误应答 RSP_NACK（CMD = `0xFF`）

| 偏移 | 长度 | 类型  | 说明                  |
| ---- | ---- | ----- | --------------------- |
| 0    | 1    | uint8 | 被拒绝的原始命令码 CMD |
| 1    | 1    | uint8 | 错误码（见 §4）        |

- DATA 总长：**2 字节**。

---

## 4. 错误码

| 错误码 | 名称            | 值   | 触发条件                          |
| ------ | --------------- | ---- | --------------------------------- |
| ERR_INVALID_ID   | `0x01` | `motor_id` 不在 1~6 范围内        |
| ERR_INVALID_LEN  | `0x02` | DATA 长度不足该命令所需最小长度    |
| ERR_UNKNOWN_CMD  | `0x03` | 命令码不在已定义列表中             |
| ERR_CHECKSUM     | `0x04` | 校验和计算结果与帧中 CHK 不一致    |

## 5. 通信流程示例

### 5.1 使能电机 1

```
发送（中间件 → 单片机）:
  5A A5 01 01 01 01 0D 0A
  │  │  │  │  │  │  │  └── TAIL_1
  │  │  │  │  │  │  └── TAIL_0
  │  │  │  │  │  └── CHK = 0x01 XOR 0x01 XOR 0x01 = 0x01
  │  │  │  │  └── LEN = 1
  │  │  │  └── CMD = 0x01 (ENABLE)
  │  │  └── HEADER_1
  │  └── HEADER_0
  └── HEADER_0

应答（单片机 → 中间件）:
  5A A5 FE 01 01 00 0D 0A
              │  │  └── CHK = 0xFE XOR 0x01 XOR 0x01 = 0xFE
              │  └── DATA[0] = 0x01 (被确认的 CMD)
              └── LEN = 1
```

### 5.2 设置电机 2 MIT 控制

```
发送:
  5A A5 03 15 [id=02] [pos: 4B] [vel: 4B] [kp: 4B] [kd: 4B] [tor: 4B] [CHK] 0D 0A
       │  │                                                                        │   │
       │  └── LEN = 21 (0x15)                                                      │   └── TAIL_1
       └── CMD = 0x03 (MIT_CTRL)                                                   └── TAIL_0
```

### 5.3 查询电机 3 状态

```
发送:
  5A A5 07 01 03 05 0D 0A
  │     │  │  │  │  │  └── TAIL_1
  │     │  │  │  │  └── CHK = 0x07 ^ 0x01 ^ 0x03 = 0x05
  │     │  │  │  └── motor_id = 3
  │     │  │  └── LEN = 1
  │     │  └── CMD = 0x07 (READ_STATUS)
  │     └── HEADER_1
  └── HEADER_0

应答:
  5A A5 80 10 [id] [state] [pos:4B] [vel:4B] [tor:4B] [Tmos] [Tcoil] [CHK] 0D 0A
       │  │                                                               │    │
       │  └── LEN = 16 (0x10)                                            │    └── TAIL_1
       └── CMD = 0x80 (RSP_STATUS)                                       └── TAIL_0
```

### 5.4 6 电机位置批量控制（CMD_ALL_POS）

```
发送:
  5A A5 10 18 [pos1:4B] [pos2:4B] [pos3:4B] [pos4:4B] [pos5:4B] [pos6:4B] [CHK] 0D 0A
       │  │                                                                  │    │
       │  └── LEN = 24 (0x18)                                               │    └── TAIL_1
       └── CMD = 0x10 (ALL_POS)                                             └── TAIL_0

  注意：默认参数为 kp=1.0, kd=0.5, vel=0.0, tor=0.0（代码内置）
```

## 6. 命令码速查表

| CMD   | 名称             | 方向       | DATA 长度 | 简要说明                   |
| ----- | ---------------- | ---------- | --------- | -------------------------- |
| `0x01` | CMD_ENABLE       | 主 → 从   | 1         | 使能电机 (0=全部)          |
| `0x02` | CMD_DISABLE      | 主 → 从   | 1         | 失能电机 (0=全部)          |
| `0x03` | CMD_MIT_CTRL     | 主 → 从   | 21        | MIT 阻尼控制               |
| `0x04` | CMD_POS_CTRL     | 主 → 从   | 9         | 位置速度控制               |
| `0x05` | CMD_SPD_CTRL     | 主 → 从   | 5         | 速度控制                   |
| `0x06` | CMD_PSI_CTRL     | 主 → 从   | 13        | 位置速度电流控制            |
| `0x07` | CMD_READ_STATUS  | 主 → 从   | 1         | 查询电机状态               |
| `0x08` | CMD_SAVE_ZERO    | 主 → 从   | 1         | 保存零点 (0=全部)          |
| `0x09` | CMD_CLEAR_ERR    | 主 → 从   | 1         | 清除错误 (0=全部)          |
| `0x0A` | CMD_LOCK_MOTOR   | 主 → 从   | 1         | 锁定电机 (0=全部)          |
| `0x10` | CMD_ALL_POS      | 主 → 从   | 24        | 6 电机位置控制             |
| `0x11` | CMD_ALL_TORQUE   | 主 → 从   | 24        | 6 电机力矩控制             |
| `0x12` | CMD_ALL_MIT      | 主 → 从   | 120       | 6 电机完整 MIT 控制         |
| `0x80` | RSP_STATUS       | 从 → 主   | 16        | 电机状态应答               |
| `0xFE` | RSP_ACK          | 从 → 主   | 1         | 命令成功应答               |
| `0xFF` | RSP_NACK         | 从 → 主   | 2         | 命令错误应答               |

## 7. 注意事项

1. **校验失败**：单片机会返回 NACK（`ERR_CHECKSUM`）后丢弃该帧，不执行任何动作。
2. **motor_id = 0**：对使能/失能/保存零点/清除错误/锁定命令，`id = 0` 表示广播全部 6 个电机，成功后仅回复一次 ACK。
3. **float 字节序**：ARM Cortex-M 为小端架构，float 直接按内存顺序传输，中间件端需以相同字节序解析。
4. **帧解析策略**：接收端通过扫描帧头 `0x5A 0xA5` 定位帧起始，再根据 LEN 字段确定帧总长，校验帧尾 `0x0D 0x0A` 后进行校验和验证。
5. **DMA 接收**：使用 UART DMA 空闲线检测（`HAL_UARTEx_ReceiveToIdle_DMA`），支持不定长帧接收，缓冲区大小 256 字节。
